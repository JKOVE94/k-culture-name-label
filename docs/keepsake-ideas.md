# 이름 포토카드 장기 보관 아이디어 (현지 수급 기준)

전제
- 라벨: NIIMBOT B1 Pro **50×80mm 감열 라벨** (롤당 95장). 실내에서 1~2년 정도 읽을 수 있고, 햇빛·열·손때에 약하다.
- 준비물은 최소로 하고, **떨어져도 일본 현지(100엔샵·편의점)에서 바로 채울 수 있는 것**만 쓴다.
- 50×80 라벨은 **チェキ(54×86) 크기 카드 슬리브**에 그대로 들어간다.

## 단계별 구성 (위로 갈수록 준비가 적음)

| 단계 | 방문자에게 주는 것 | 준비물 | 현지 수급처 | 비고 |
|---|---|---|---|---|
| 0 | 라벨만 + 「スマホケースに挟んでね」 안내 | 없음 | — | 투명 폰케이스에 포카를 끼우는 문화가 있어 그대로 보관 가능 |
| 1 (기본) | 라벨 + **카드 슬리브** | トレカスリーブ(チェキ/ミニ 사이즈) | 다이소·세리아·캔두 推し活 코너, 문구·카드게임 코너 | 수십 장 묶음이라 1장당 몇 엔 수준. 손때·긁힘 방지 |
| 2 | 라벨을 **흰 카드지**에 붙여 슬리브에 | 무지 카드 / 名刺カード / 画用紙 | 100엔샵 문구 코너 | 빳빳해져 진짜 포카 느낌 |
| 3 (선택) | 라벨 + **키링 케이스** | キーホルダー付きトレカケース, ボールチェーン | 100엔샵 推し活 코너 (110~220엔) | 가방에 다는 굿즈. 수량 한정(이벤트 상품 등)으로 운영 |

### 떨어졌을 때 대체 순서
```
키링 케이스 소진 → 슬리브만     슬리브 소진 → 라벨 + 폰케이스 안내
카드지 소진     → 라벨만 슬리브에    라벨 소진 → 디지털 이름카드(화면 저장)만
```

## 오래 남기는 보조 수단
- **디지털 이름카드**: 방문자 화면의 「名前カードをスマホに保存」(컬러 PNG). 라벨이 흐려져도 사진첩에 남는다. QR을 보여 줄 때 저장하도록 스태프가 한마디 안내.
- **빛 피하기 안내**: 「直射日光を避けてね」 한 줄. 슬리브·케이스에 넣으면 손때·긁힘으로 지워지는 건 막힌다.
- (참고) 정말 안 바래는 인쇄는 열전사 프린터(Niimbot M2·M3·B18 등) + PET 라벨 조합(8~10년). 이번 부스 범위 밖.

## 현장 운영 메모
- 슬리브 입구가 위로 오게 넣어 주면 빠지지 않는다.
- 라벨 롤 교체 시 스태프 화면의 라벨 크기가 **50×80 포토카드**인지 확인.
- 50×80은 롤당 95장이라 50×30(230장)보다 롤이 2~3배 더 필요하다. 예비 롤은 넉넉히.
